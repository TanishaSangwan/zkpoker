## Finding

[P2] **1. `settle_table_by_hand` never validated submitted cards are real, distinct deck cards**

`Class: Oracle trust concentration` · `cairo/src/lib.cairo` (`settle_table_by_hand`) / `cairo/src/poker_hand.cairo` (`evaluate_5`) · Confidence: 75 · Severity: Medium

**Description**
Neither `settle_table_by_hand` nor `poker_hand::evaluate_5`/`best_of_7` checked that a submitted card is `< 52`, or that no card value repeats — within one seat's 7 cards, across different seats' hole cards, or against the shared community cards. An out-of-range value (e.g. `200`) silently folded via `% 13` into a valid-looking rank instead of reverting; and a dealer could submit the same real card value 3-4 times to fabricate a trips/quads impossible with a real 52-card deck. Since `settle_table_by_hand` is dealer-only and has no on-chain link to the seed commitment yet (an already-known, separately-tracked gap), this didn't hand the dealer new *power* over the pot — they could already name an arbitrary winner via plain `settle_table`. What it undermined was `settle_table_by_hand`'s own specific claim: that the winner is "a deterministic function of the submitted cards, checkable by anyone." Without this fix, that check only confirmed the score was *self-consistent*, not that it corresponded to a possible real hand.

**Status: FIXED.** Added `poker_hand::assert_valid_deck_cards(cards: Span<u8>)` — asserts every card is `< 52` and pairwise-distinct. `settle_table_by_hand` now builds the full combined card set (5 community + 2 per seat) and validates it before any scoring happens. New unit tests in `poker_hand.cairo` (5 tests: accepts distinct real cards, rejects out-of-range, rejects duplicate, boundary 51 accepted, boundary 52 rejected — all passing) plus 2 new integration regression tests in `cairo/tests/test_hand_eval.cairo` (out-of-range card, duplicate card across seats — unverified, same `snforge`-unavailable caveat as the rest of that directory).

**Required Tests**
- (Done, unit-level) A mock/direct call to `assert_valid_deck_cards` with a card `>= 52` reverts with `BAD_CARDS`; with a duplicate value reverts with `BAD_CARDS`; with 7 genuinely distinct real cards succeeds.
- (Written, unverified) `settle_table_by_hand` with an out-of-range or duplicated card reverts with `BAD_CARDS` instead of settling.
